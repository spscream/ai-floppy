# floppy

*[In English](README.md)*

floppy — плагин для Claude Code и Cursor. Он даёт кодящему агенту две вещи:
память, остающуюся в вашем репозитории, и две процедуры, которые ею пользуются.

- Процедура `start` сообщает агенту, где остановилась прошлая сессия.
- Процедура `wrap` сохраняет то, что узнала эта сессия.
- Корректность процедур держат три проверки: проверка списка файлов, линтер
  памяти и замок сессии.

Память — это набор markdown-файлов. Git хранит их вместе с вашим кодом. Вторая
машина получает память одним клоном.

## Установка

```
claude plugin marketplace add spscream/ai-floppy
claude plugin install floppy@floppy
```

Cursor, локальный чекаут и что делать, если обновление ничего не скопировало:
[Установка и init](docs/guide/install.ru.md).

## Дальше

Выполните `init` один раз в каждом репозитории. Он пишет `.floppy/run` и
`.floppy/config`, создаёт индекс памяти и файл состояния, и добавляет в ваш
`AGENTS.md` указатель на соглашения.

Пять скиллов: `init`, `agent-memory`, `start`, `workstatus`, `wrap`.
Что делает каждый: [Пять скиллов](docs/guide/skills.ru.md).

## Модель памяти

[docs/memory-model.ru.md](docs/memory-model.ru.md) — дизайн, к которому движутся пути:
два пространства имён (кому можно читать) и две независимые оси под ними (о чём
это и где это верно). **Это дизайн, а не текущее состояние.** Прочитайте его,
прежде чем менять любой путь в скриптах. Он существует потому, что раскладку
переименовали трижды за один день, и каждое переименование правило модель,
которую никто не записал.

[docs/lessons.ru.md](docs/lessons.ru.md) — чего стоили те переименования и почему
внешняя раскладка выводится из файловой системы, а не из флага в конфиге. Это
уроки про *floppy*.

## База знаний

[knowledge/README.md](knowledge/README.md) — находки про сам кодящий харнесс,
верные независимо от того, пользуетесь вы floppy или нет: почему линтер обошёл
пустое дерево и остался зелёным, почему сюита зависает на открытом stdin, откуда
на самом деле берётся запрет на субагентов, чего не восстанавливает `/rewind`.

От `docs/lessons.md` она отделена аудиторией и несёт контракт, которого у того
файла нет: каждая заметка называет дату и среду, против которых её проверяли, и
команду для перепроверки, — потому что заметку про чужой инструмент никто не
перечитывает, пока она уже не обожгла. `python3 scripts/knowledge-rot-check.py`
перечисляет те, что состарились: он сообщает, а не преграждает.

## Релизы

См. [CHANGELOG.md](CHANGELOG.md). Для каждого релиза он отвечает на один вопрос,
на который без него не ответить: нужна ли этому обновлению ещё и новая копия
файла-прокладки? `.floppy/run` — это копия, и ни одно обновление плагина её не
меняет.
