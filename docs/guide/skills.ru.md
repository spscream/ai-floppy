# Шесть скиллов


Claude Code и Cursor показывают имена по-разному. Claude Code добавляет имя
плагина, например `floppy:start`. Cursor показывает короткое имя, например
`/start`, а плагин отображает как «Created by Floppy». Этот документ использует
короткое имя. Только короткое имя верно в обоих приложениях.

- **`init`** — настройка. См. [Установка и init](install.ru.md).
- **`agent-memory`** — правила для памяти. У этого скилла нет шагов. Остальные
  скиллы этим правилам подчиняются. Одна заметка содержит один факт. У каждой
  заметки есть поле `metadata.evidence` с одним из значений: `measured`, `read`,
  `decided`, `sourced`. У индекса три уровня: `MEMORY.md`, затем
  `<half>/INDEX.md`, затем `<half>/<group>/INDEX.md`. Файл `quota.lock` держит
  ограничения размера. Каждый факт принадлежит одной области: проект,
  кросс-проект, рабочее место или машина. Факт, верный больше чем для одного
  проекта, идёт в кросс-проектную область `common/`, которую память подключает
  по одной ссылке на аудиторию. Заметка пишется в момент появления факта, а не
  собирается в конце сессии.
- **`start`** — готовит новую сессию, до первой правки. Агент читает файл
  состояния. Затем агент находит половину памяти, относящуюся к этой задаче, и
  читает руководство и индекс этой половины. Если памяти в репозитории ещё нет,
  агент этот шаг пропускает. Затем агент выполняет `bash .floppy/run status`,
  потому что живые факты надёжнее документов.
- **`workstatus`** — докладывает состояние по ходу сессии: состояние git,
  расхождение с удалённым, фоновые задачи, конфигурацию памяти, репозиторий
  памяти рабочего места и возраст файла состояния.
- **`wrap`** — закрывает сессию. Агент берёт замок. Большая часть фактов уже
  записана заметками в момент их появления; здесь агент добавляет только то,
  что осталось, обновляет файл состояния и записывает незавершённую работу.
  Затем агент выполняет `bash .floppy/run check`, который ничего не меняет и
  показывает результат линта, проверку списка файлов и дифф. Последним агент
  выполняет `bash .floppy/run commit`, который индексирует, коммитит, пушит и
  освобождает замок.
- **`consolidate`** — сливает и чистит память, когда срабатывает
  предупреждение о размере, или перед поднятием лимита в `quota.lock`. Агент
  читает одну половину памяти, предлагает слияния, переписывания и удаления,
  каждое с причиной, и применяет только то, что человек утвердил. Если память
  после этого умещается в лимит, лимит не поднимается. Пустой результат — тоже
  результат: именно его тогда записывает коммит с поднятием.


## Что каждый скилл говорит о себе

Блок ниже собирается при сборке сайта из поля `description` файла
`skills/<name>/SKILL.md`. Он остаётся английским: эти файлы читает модель, и
их формулировки — это поведение, а не текст для чтения. Поэтому страница не
может описать скилл иначе, чем его видит агент.
